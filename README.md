## Assignment 01 — Member Profile

**File:** `assignment-01-member-profile.cpp`

### ?? Description

This is an introductory C++ program that displays a member's profile for the ASVA Hardware Club. It demonstrates the use of:

- **Global variables** — storing member data outside of any function
- **Basic data types** — `string` and `int`
- **Standard output** — printing formatted text to the console using `cout`

### ?? Member Profile Fields

| Variable                      | Type     | Description                              |
|-------------------------------|----------|------------------------------------------|
| `name`                        | `string` | Full name of the club member             |
| `department`                  | `string` | Member's academic department             |
| `level`                       | `int`    | Current academic level (e.g. 300)        |
| `area_of_hardware`            | `string` | Member's area of interest in hardware    |
| `number_of_hardware_projects` | `int`    | Number of hardware projects completed    |

### ?? Sample Output

```
Name: Oluwole David
Department: Biomedical Engineering
Level: 300
Area of Hardware: dee
Number of Hardware Projects: 0
```

### ?? How to Compile & Run

Make sure you have a C++ compiler installed (e.g. `g++`).

**Linux / macOS:**
```bash
g++ assignment-01-member-profile.cpp -o member-profile
./member-profile
```

**Windows:**
```powershell
g++ assignment-01-member-profile.cpp -o member-profile.exe
.\member-profile.exe
```
